# 2026-07-30 PLM 工艺路线项目名称、成本字段与同套 BOM 颜色差异实施说明

## 1. 实施范围

本次按《PLM工艺路线项目名称成本字段与同套BOM颜色差异方案》落地代码，涉及 Product、Process 和 Inventory 既有附属资料，不新增 BOM、BOMLine 或 SKU 根对象。

## 2. 已实施内容

### 2.1 新建工艺路线显示项目名称

- `ProjectProcessRoutePanel.vue` 使用自定义弹窗标题。
- 新建和编辑工艺路线时，标题右侧展示已传入的项目名称，名称缺失时回退显示产品编码。

### 2.2 成本字段

- `BomSummaryVO`、`ProductBomWorkbenchVO` 新增：`rdTotalCost`、`formalAverageUnitCost`、`currentBomSkuUnitCost`。
- `ProjectDetailVO` 新增：`totalCost`、`currencyCode`。
- `BomLedgerServiceImpl` 以测试 BOM 成本与所有有效候选/正式 BOM 路线当前成本快照聚合研发总成本；正式平均单个成本按有效颜色数量加权平均；当前 BOM 单个 SKU 成本按当前 BOM 的颜色副本成本平均。
- 项目详情接口复用 BOM 汇总的 `rdTotalCost` 作为项目总成本，前端项目详情打开时拉取该字段并展示。
- BOM 工作台和产品详情 BOM 查看页显示三个成本指标；每个颜色副本显示对应单个 SKU 成本。

### 2.3 同套 BOM 的颜色差异副本

- 新增迁移 `V20260730_1100__bom_color_variant_group.sql`。
- `plm_product_bom_route` 扩展 `shared_bom_group_code`、`route_variant_no`、`variant_name`、`variant_source_type`。
- `plm_product_bom_item` 扩展 `shared_bom_group_code`，用于查询快照。
- 历史有效路线回填为 `BOM-{product_bom_id}`、`BASE`、`基础用料`。
- 路线唯一索引调整为 BOM、工艺路线和副本编号；物料明细唯一索引调整为 BOM、路线和行号。
- 保存候选 BOM 明细支持同组多个颜色副本，校验同组副本编号唯一、同组绑定同一工艺路线、颜色在同一 BOM 内唯一归属、每个副本必须有颜色和明细。
- 编辑器支持复制当前 BOM：复制后生成新副本草稿，清空适用颜色，保留可继续修改的物料明细；保存时一次提交所有副本。
- SKU 查询继续按颜色定位唯一 `product_bom_route_id`，并返回副本信息与对应单个 SKU 成本。
- 候选 BOM 管理页将副本保留在同一 BOM 工作台内，产品详情的 BOM 查看可选择具体颜色副本查看明细。
- 新建候选 BOM、BOM 继承均补齐默认 `BASE` 副本字段，避免迁移后的非空约束影响原流程。

## 3. 主要改动文件

- 后端：`ProductBomWorkflowService.java`、`BomLedgerServiceImpl.java`、`ProductBomServiceImpl.java`、`BomInheritanceService.java`、相关实体、DTO、VO、`ProjectServiceImpl.java`。
- 数据库：`V20260730_1100__bom_color_variant_group.sql`。
- 前端：`BomRouteEditor.vue`、`ProjectBomPanel.vue`、`ProjectProcessRoutePanel.vue`、`ProductBomViewer.vue`、`ProjectCenterView.vue`、BOM/项目 API 与类型定义。

## 4. 预期效果

1. 新建工艺路线弹窗能直接看到所属项目名称。
2. BOM 管理和产品 BOM 查看可看到研发总成本、正式版本平均单个成本、当前 BOM 单个 SKU 成本；项目详情显示总成本。
3. 同一套 BOM 可复制为多个颜色差异副本，仅调整色粉等差异物料，并分别绑定适用颜色。
4. BOM 管理界面仍把这些副本收纳在一个候选 BOM 中；SKU 查询时按所选颜色返回唯一的 BOM 副本及成本。
