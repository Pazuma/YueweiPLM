## 1. 本次目标

本次实现 M1 公共能力闭环：

1. 用户使用账号密码登录，登录成功返回 Bearer token。
2. 请求携带 token 后，后端能拿到当前用户 `CurrentUser`。
3. `GET /api/v1/auth/profile` 返回当前用户资料。
4. `POST /api/v1/auth/logout` 使 token 失效。
5. 未携带 token 或 token 无效访问业务接口时，统一返回 401 与业务码 `40101`。
6. 操作日志写入 `plm_operation_log`，包含操作人、动作、业务对象、requestId 和时间。
7. Product 冻结动作不再信任 query 参数里的 `operator`，改用当前登录用户并写入 `PRODUCT_FREEZE` 日志。

## 3. 修改代码

### 3.1 登录与当前用户模块

新增：

- `src/main/java/com/yuewei/plm/module/auth/controller/AuthController.java`
- `src/main/java/com/yuewei/plm/module/auth/dto/LoginDTO.java`

- `src/main/java/com/yuewei/plm/module/auth/service/TokenSessionService.java`

- `src/main/java/com/yuewei/plm/module/auth/vo/LoginVO.java`
- `src/main/java/com/yuewei/plm/module/user/entity/SysUser.java`
- `src/main/java/com/yuewei/plm/module/user/repository/SysUserRepository.java`

核心逻辑：

- `AuthServiceImpl.login` 根据 `username` 查询 `sys_user`。
- 用户不存在、禁用、删除或密码错误时统一抛出 `40101 / 账号或密码错误`，不暴露账号枚举线索。
- 密码使用 `BCryptPasswordEncoder` 校验 `password_hash`。
- 登录成功后组装 `CurrentUser(userId, username, displayName, allPermissions)`。
- `InMemoryTokenSessionService` 使用 `SecureRandom` 生成 token，默认有效期 8 小时。
- 登录成功写入 `AUTH_LOGIN` 操作日志。
- `profile` 从 `CurrentUserContext` 读取当前用户。
- `logout` 解析 Bearer token，写入 `AUTH_LOGOUT` 日志并让 token 失效。

### 3.2 安全过滤器

修改：

- `src/main/java/com/yuewei/plm/common/security/SimpleTokenAuthenticationFilter.java`
- `src/main/java/com/yuewei/plm/common/config/SecurityConfig.java`

核心逻辑：

- 保留 public path：`/api/v1/health/**`、`/api/v1/auth/login`、Swagger、OpenAPI。
- `app.security.enabled=false` 时放行，便于开发环境低成本联调。
- `app.security.enabled=true` 时解析 `Authorization: Bearer <token>`。
- token 缺失、格式错误、过期或不存在时，直接返回：

```json
{
  "code": 40101,
  "message": "未登录或登录已失效",
  "data": null
}
```

- token 有效时写入：
  - `CurrentUserContext`
  - Spring Security `SecurityContext`
- 请求结束后在 `finally` 中清理上下文，避免线程复用污染。
- `SecurityConfig` 增加无状态 Session 策略和统一 `AuthenticationEntryPoint`。
- `SecurityConfig` 提供 `PasswordEncoder` Bean。

### 3.4 Product freeze 改造

修改：

- `src/main/java/com/yuewei/plm/controller/ProductController.java`
- `src/main/java/com/yuewei/plm/service/ProductService.java`
- `src/main/java/com/yuewei/plm/service/impl/ProductServiceImpl.java`

核心逻辑：

- `POST /api/v1/products/{id}/freeze` 不再接收 `operator` query 参数。
- 操作人统一从 `CurrentUserContext` 获取。
- 冻结时写入：
  - `frozen_by = currentUser.displayName`
  - `lock_operator_user_id = currentUser.userId`
  - `lock_operator_user_name = currentUser.displayName`
  - `updated_by = currentUser.displayName`
- 同步写入 `PRODUCT_FREEZE` 操作日志：
  - `business_type=PRODUCT`
  - `business_id=productId`
  - `business_code=productCode`
  - `business_name=productName`
  - `detail_json={"reason":"冻结原因"}`

## 10. 注意事项

- `InMemoryTokenSessionService` 是 M1 临时实现，服务重启 token 会失效，多实例不共享。后续可迁移 Redis。
- dev 环境 `application-dev.yml` 默认 `APP_SECURITY_ENABLED=false`，M1 验收必须显式设为 `true`。
- 当前 migration 目录未绑定 Flyway 自动执行，需要按项目部署方式确认是否手动执行 SQL。
- `POST /api/v1/operation-logs/test` 只用于 M1 验证，后续进入 M2 前建议只在 dev 环境开放或删除。
