> 目标：完成 M5 冻结、发布、归档、放弃门禁的前端接入，并核对后端 M5 接口合同。

## 1. 任务理解

本次把 M5 后端生命周期接口接入到前端项目中心。用户打开 Product 项目详情后，可以在“当前节点”区域看到发布门禁面板，并执行：

```text
发布门禁预检
冻结
发布
归档
放弃
```

发布前端不自行判定资料齐备，最终仍以后端门禁为准。当前端调用发布接口遇到 `code=40307` 时，页面会把后端返回的 `data.missingItems` 展示出来，避免用户只看到一句“发布失败”。

### 3.2 新增 M5 门禁面板组件

文件：

```text
D:\Yuewei\git\YUEWEI\plm-web\src\views\project\components\ProjectReleaseGatePanel.vue
```

主要能力：

```text
1. 打开组件后自动调用 GET /projects/{projectId}/release-gate。
2. 展示 passed=true/false。
3. 展示 missingItems 缺失项。
4. 展示 BOM、工艺路线、图纸、SOP/SIP、测试资料计数。
5. 支持重新预检。
6. 支持冻结、发布、归档、放弃。
7. 发布失败遇到 code=40307 时读取 error.response.data.data，并把 missingItems 更新到页面。
8. 动作成功后 emit changed，让父页面刷新时间轴和列表。
```

关键逻辑：

```text
release-gate code=0 且 passed=false：
  预检成功，但发布门禁未通过，页面展示缺失项。

publish code=40307：
  发布动作失败，页面展示后端返回的缺失项清单。

abandon：
  必须填写原因，否则不发送请求。
```

## 9. 注意事项

1. 前端按钮禁用只是体验优化，后端仍必须做状态、权限、资料门禁校验。
2. `release-gate` 的 `passed=false` 不代表接口失败，不能用全局错误提示吞掉。
3. `publish` 的 `40307` 必须显示 `missingItems`。
4. 放弃项目必须填写原因。
5. 归档不删除附件，归档后仍要验证文件中心可查。
6. 本次没有新增 Product 状态，`abandoned` 仍通过 `lockStatus=abandoned` 表达。
7. 后续如果后端新增门禁项，前端优先显示后端 `message`，不要强依赖固定 code 枚举。
