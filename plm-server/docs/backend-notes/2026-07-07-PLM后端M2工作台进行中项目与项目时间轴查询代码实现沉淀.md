## 5. 接口说明

### 5.1 工作台进行中项目

```http
GET /api/v1/workbench/projects/in-progress?page=1&size=20
Authorization: Bearer {{token}}
```

说明：

- 进行中状态为 `draft`、`developing`、`reviewing`。
- 支持 `keyword`、`productType`。
- 返回分页 `ProjectSummaryVO`。

### 5.2 项目列表

```http
GET /api/v1/projects?page=1&size=20&productType=product_line
Authorization: Bearer {{token}}
```

说明：

- 支持 `keyword`、`productType`、`status`、`ownerUserId`。
- 返回分页 `ProjectSummaryVO`。

### 5.3 项目详情

```http
GET /api/v1/projects/{{projectId}}
Authorization: Bearer {{token}}
```

说明：

- `projectId` 等同 `productId`。
- 返回 Product 基础信息、负责人、当前节点、时间轴。

### 5.4 项目摘要

```http
GET /api/v1/projects/{{projectId}}/summary
Authorization: Bearer {{token}}
```

说明：

- 返回项目弹窗头部或局部刷新所需摘要。

### 5.5 项目时间轴

```http
GET /api/v1/projects/{{projectId}}/timeline
Authorization: Bearer {{token}}
```

说明：

- 返回固定 6 个节点。
- `nodeStatus` 为 `completed`、`current`、`pending`。
- 仅有一个 `current` 节点。
- `documentCount` 当前返回 `0`。

### 6.2 登录并保存 token

```http
POST {{baseUrl}}/api/v1/auth/login
Content-Type: application/json
X-Request-Id: m2-login-001
```

Body:

```json
{
  "username": "{{username}}",
  "password": "{{password}}"
}
```

后置脚本：

```javascript
const json = pm.response.json();
pm.test("登录成功", function () {
  pm.expect(json.code).to.eql(0);
  pm.expect(json.data.token).to.be.a("string");
});
pm.environment.set("token", json.data.token);
```

预期：

- `code=0`
- `data.token` 有值。

预期：

- `nodes.length=6`
- 只有一个 `current`
- 当前节点之前为 `completed`
