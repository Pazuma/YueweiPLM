# 2026-07-18 PLM BOM 实际业务板块代码实现沉淀

## 1. 实现结论

本轮已实现项目工作台 BOM 编辑、路线/颜色/物料绑定、XLSX 预校验与原子提交、错误报告、多路线成本快照、新型号继承、审核/冻结/发布、版本复制，以及 BOM/工艺只读台账和产品详情展示。

正式模型为：`Product -> 正式 BOM 版本 -> 多条工艺路线 -> 每条路线多个颜色 + 一份路线 BOM + 一份成本快照`。同版本颜色唯一归属路线，SKU 按颜色解析唯一路线、BOM 和成本。

## 6. 边界与注意事项

- BOM 管理中心和工艺管理中心不提供编辑、删除或 ERP 同步入口。
- 代码审查后已补齐：路线覆盖时同步归档旧颜色/明细、导入 BOM 产品归属与可编辑校验、同路线多行颜色合并、台账仅显示 released、导入令牌原子抢占、冻结/发布时间轴节点门禁。
- 当前 BOM/SKU 与 Route/SKU 接口仍返回全量列表，BOM 中心由前端切片分页；这是中等规模性能债，不影响当前数据正确性，大数据量上线前应改为后端分页合同。
- 本轮不包含 ERP、MES、WMS、CRM、OA 或钉钉正式集成。
- 线上上线前必须使用上表在真实浏览器中完成 14 项人工验收，特别是导入下载、真实文件内容、多路线切换和发布写入场景。
