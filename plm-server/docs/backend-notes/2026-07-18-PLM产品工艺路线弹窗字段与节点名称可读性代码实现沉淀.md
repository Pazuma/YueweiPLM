## 4. 关键代码

### 4.1 节点核对表使用工序名称

文件：`ProjectProcessRoutePanel.vue`

```ts
interface NodeCheckRow {
  displayOrder: number
  operationCode: string
  operationName: string
  predecessorNodeNames: string[]
  successorNodeNames: string[]
  backendPersisted: boolean
}

function buildNodeCheckRows(operations: ProcessOperationSavePayload[], persisted: boolean): NodeCheckRow[] {
  const sorted = [...operations].sort((left, right) => left.sequenceNo - right.sequenceNo)
  return sorted.map((operation, index) => {
    const operationCode = operation.operationCode || `OP-${operation.sequenceNo}`
    return {
      displayOrder: index + 1,
      operationCode,
      operationName: operation.processName,
      predecessorNodeNames: index > 0 ? [sorted[index - 1].processName || '上一道工序'] : [],
      successorNodeNames: index < sorted.length - 1 ? [sorted[index + 1].processName || '下一道工序'] : [],
      backendPersisted: persisted
    }
  })
}
```

逻辑说明：

1. `operationCode` 仍保留在表格中，供技术追溯。
2. 前置节点、后置节点改为取相邻工序的 `processName`。
3. 第一行前置节点为空，最后一行后置节点为空，页面显示 `--`。

## 5. 前端测试方式与合格标准

### 5.1 新建工艺路线弹窗字段

测试步骤：

1. 启动后端和前端。
2. 登录系统。
3. 进入“项目中心”或工作台中能打开工艺路线的项目。
4. 点击“新建工艺路线”。

合格标准：

1. 弹窗内不显示“适用型号”。
2. 弹窗内不显示可自由输入的“适用颜色”。
3. 路线名称、版本号、编码预览、BOM 版本、最终确认、备注、工序明细仍可正常查看和编辑。

### 5.2 工序明细标题

测试步骤：

1. 在“新建工艺路线”弹窗选择标准工艺路线模板。
2. 查看“工序明细”区域。
3. 点击“添加工序”，再执行上移、下移、删除。

合格标准：

1. 工序明细上方显示：顺序、工序编码、工序名称、标准工时、工艺参数、质量要求、操作。
2. 标题和下方输入控件在桌面端对齐。
3. 添加、移动、删除工序后标题不消失、不错位。
4. 工序名称通过工序库选择，工序编码由选择结果带出。

### 5.3 节点配置核对表

测试步骤：

1. 选择包含多道工序的模板，例如注塑、修边、组装。
2. 查看弹窗底部“节点配置核对表”。
3. 保存后查看路线详情里的“节点配置核对表”。

合格标准：

1. 前置节点、后置节点显示工序名称，例如“注塑成型”“修边去披锋”“组装”。
2. 前置节点、后置节点不显示 `PROC_...` 作为主要内容。
3. 第一行前置节点显示 `--`。
4. 最后一行后置节点显示 `--`。
5. 工序编码列仍保留编码，用于技术追溯。

### 5.4 保存回显

测试步骤：

1. 新建一条工艺路线。
2. 选择工序库中的工序，填写标准工时、工艺参数、质量要求。
3. 点击“保存完整路线”。
4. 刷新页面后重新进入该项目工艺路线。

合格标准：

1. 保存接口不出现 400、404、500。
2. 路线可回显。
3. 工序编码、工序名称、标准工时、工艺参数、质量要求完整。
4. 节点核对表保存前后展示一致。

## 7. 后续维护建议

1. 颜色字段不要再用自由输入，后续应由“系统管理 - 编码管理”统一维护颜色名称和颜色编码。
2. 如果未来确实要表达不同型号、颜色、材料导致的路线差异，应先明确仍属于 Product 子版本还是后续 SKU 视图，避免在产品级路线弹窗中恢复“适用型号”自由文本。
3. 节点关系展示坚持“业务名称优先、编码辅助追溯”原则，工艺、BOM、文件中心都应采用相同可读性口径。
4. 工序库是工艺路线录入的基础资料来源，后续需要补齐工序库的停用、归档、引用校验，防止已被路线引用的工序被随意删除。
5. 当前测试覆盖了弹窗展示和节点名称展示；后续接入颜色编码管理时，应新增测试覆盖颜色编码下拉、保存 payload、回显展示。
