新增接口：

```http
GET /api/v1/inventories/material-lookup?inventoryCode=xxx
```

目标效果：

- 匹配到 `plm_inventory.inventory_code` 时，返回物料名称、规格、单位、供应商、单价和币种。
- 未匹配时返回 `matched=false` 和明确提示，前端允许继续人工录入候选 BOM。

- `src/main/java/com/yuewei/plm/module/bom/service/impl/ProductBomServiceImpl.java`

实现内容：

- 工作台候选 / 正式可编辑 BOM 导入支持新模板列：供应商、单价、单个成本。
- 工作台导入遇到未知物料编码时不阻断预览，标记 `materialSource=manual`、`unmatchedFlag=1`。
- 历史 BOM 导入仍保持严格物料匹配，未知物料继续阻止导入并进入错误报告。
- 保存路线 BOM 时持久化供应商快照、单价快照、单个成本快照、人工物料标记。
- 单个成本为空时按 `quantity * unitCost` 计算；单价和单个成本均校验不能为负。

## 5. 前端直接测试方式与合格标准

### 5.1 工作台手工新增：物料编码匹配成功

测试方式：

1. 启动前后端。
2. 打开前端“工作台 → 项目流程 → BOM 工作台”。
3. 选择一个候选 BOM，点击“维护路线与 BOM”。
4. 点击“添加物料”。
5. 在“物料编码”输入物料库已存在编码，并让输入框失焦。

合格标准：

- 物料名称自动带出。
- 规格、单位、供应商、单价自动带出。
- 单个成本自动按 `数量 × 单价` 计算。
- 点击保存后再次打开，字段能正确回显。

### 5.2 工作台手工新增：物料编码未匹配

测试方式：

1. 在“物料编码”输入不存在的编码。
2. 观察行内提示。
3. 手工填写物料名称、单位、单价等字段。
4. 点击保存。

合格标准：

- 页面出现“未匹配”标记或提示。
- 候选 BOM 不被阻止保存。
- 保存后该行保留人工录入内容。
- 工作台面板风险提示中“人工物料”数量增加。

### 5.3 供应商选择

测试方式：

1. 输入一个能带出默认供应商的物料编码。
2. 查看供应商列。
3. 展开供应商选择控件。

合格标准：

- 供应商列是选择控件。
- 命中物料默认供应商后自动选中。
- 保存后刷新仍显示供应商快照。

说明：首期未接入独立供应商中心下拉接口，供应商选项来自库存匹配结果和 BOM 已有行；后续如果接供应商中心 API，只替换选项来源即可。

### 5.4 单价和单个成本

测试方式：

1. 新增 BOM 行，填写数量 `2`、单价 `3.5`。
2. 修改数量为 `3`。
3. 修改单价为 `4.2`。

合格标准：

- 初始单个成本为 `7`。
- 数量改为 `3` 后，单个成本变为 `10.5`。
- 单价改为 `4.2` 后，单个成本变为 `12.6`。
- 单价或单个成本为负数时不能通过保存 / 导入校验。

### 5.5 XLSX 模板下载

测试方式：

1. 工作台 BOM 点击“导入 XLSX”。
2. 点击“下载模板”。
3. 打开下载的模板查看表头。

合格标准：

- 模板包含：行号、路线编码、路线名称、适用颜色、物料编码、物料名称、规格、单位、用量、供应商、单价、单个成本、损耗率、替代料标识、备注。
- Excel 可以正常打开。

### 5.6 XLSX 导入：合法文件

测试方式：

1. 按模板准备合法 xlsx。
2. 上传到当前候选 BOM。
3. 查看导入预览。
4. 点击“确认入库”。

合格标准：

- 预览状态为“预校验通过”。
- 错误行数为 0。
- 自动匹配、人工录入、供应商缺失、成本缺失统计显示正确。
- 确认入库后 BOM 路线明细出现对应物料行。
- 供应商、单价、单个成本、备注正确回显。

### 5.7 XLSX 导入：错误报告

测试方式：

1. 上传表头错误、用量为 0、单价为负、颜色编码不存在等异常 xlsx。
2. 查看预览。
3. 下载错误报告。

合格标准：

- 预览状态为“预校验未通过”。
- “确认入库”不能提交。
- 错误报告能下载。
- 错误报告包含原始行号、字段、原值、错误原因。

### 5.8 工作台风险提示

测试方式：

1. 保留至少一行人工物料。
2. 保留一行供应商为空。
3. 保留一行单价或单个成本为空。
4. 回到 BOM 工作台主面板。

合格标准：

- 主面板显示“人工物料 N”。
- 主面板显示“供应商缺失 N”。
- 主面板显示“成本缺失 N”。
- 数量与当前 BOM 路线明细一致。

### 5.9 BOM 管理中心只读查看

测试方式：

1. 将候选 BOM 后续确认 / 发布为正式 BOM。
2. 打开 BOM 管理中心。
3. 点击对应产品 / 型号详情。

合格标准：

- BOM 管理中心只展示正式 BOM 台账。
- 详情中能看到 BOM 明细、关联工艺路线、关联 SKU。
- 明细能看到供应商、单价、单个成本。
- BOM 管理中心不提供编辑入口，编辑仍回工作台。

## 7. 本次实现差异和注意事项

- 成本权限本次不设置，单价、单个成本、成本合计正常展示。
- 工作台导入允许候选 / 正式可编辑 BOM；已冻结或已发布 BOM 仍阻止导入。
- 工作台导入未知物料不阻断，历史 BOM 导入未知物料仍阻断。

- 前端供应商控件使用轻量原生 select。原因是 Element Plus `ElSelect` 在抽屉 + 动态表格 + 测试 DOM 组合下出现递归更新；原生 select 保留“选择”业务形态，并避免测试和运行时不稳定。
