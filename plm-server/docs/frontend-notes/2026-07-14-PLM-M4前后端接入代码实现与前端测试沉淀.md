### 4.2 API 接入层

- `../plm-web/src/api/request.ts`
- `../plm-web/src/api/modules/bom.ts`
- `../plm-web/src/api/modules/process.ts`
- `../plm-web/src/api/modules/attachment.ts`

代码逻辑：

- `request.ts` 继续统一封装 Axios，请求 JSON 时保留默认 `Content-Type`。
- 当请求体是 `FormData` 时，自动移除固定 JSON 头，让浏览器生成 multipart boundary。
- `bom.ts` 对接项目级 BOM、BOM 明细、冻结接口。
- `process.ts` 对接项目级工艺路线、工序数组保存、锁定接口。
- `attachment.ts` 对接时间轴节点上传、节点附件查询、文件中心分页查询、详情、下载、删除接口。

使用这些技术的原因：

- Axios 适合统一处理 token、错误、Blob 下载和响应包裹结构。
- FormData 是浏览器原生 multipart 上传能力，文件上传不应手动拼 boundary。
- TypeScript DTO 直接保留后端字段，例如 `productBomId`、`processId`、`attachmentId`，减少前后端字段映射出错。

### 4.3 项目详情页 M4 组件

- `../plm-web/src/views/project/components/ProjectBomPanel.vue`
- `../plm-web/src/views/project/components/ProjectProcessRoutePanel.vue`
- `../plm-web/src/views/project/components/TimelineAttachmentPanel.vue`
- `../plm-web/src/views/project/ProjectCenterView.vue`
- `../plm-web/src/components/FileUpload/index.vue`

代码逻辑：

- `ProjectBomPanel` 负责项目 BOM 列表、详情、创建、编辑、明细增删改、冻结。
- `ProjectProcessRoutePanel` 负责工艺路线列表、详情、工序顺序、工艺参数 JSON、质量要求和锁定。
- `TimelineAttachmentPanel` 负责当前节点文件选择、分类、版本、备注、上传、下载、删除。
- `ProjectCenterView` 在 Product/SKU 详情区域嵌入上述组件，附件变更后刷新时间轴附件数量。
- `FileUpload` 从旧的假上传函数改为真实 `uploadTimelineAttachment`，要求调用方传入 `projectId` 和 `nodeKey`。

冻结/锁定规则：

- BOM 的 `status=frozen` 后，前端隐藏或禁用编辑、明细修改和删除动作。
- 工艺路线的 `status=locked` 后，前端隐藏或禁用路线编辑和工序维护动作。
- 前端只做体验层只读控制，最终不可修改仍以后端业务校验为准。

### 4.4 文件中心

- `../plm-web/src/views/file/FileCenterView.vue`
- `../plm-web/src/utils/file.ts`

代码逻辑：

- 文件中心改为真实调用 `GET /api/v1/file-center/attachments`。
- 支持关键字、项目 ID、节点 key、文件分类筛选。
- 支持分页、下载、删除。
- 下载使用 Blob，并在下载后释放 Object URL。
- 空结果和查询失败分开展示，不用空数组掩盖接口错误。

## 8. 前端手工测试步骤和合格标准

### 8.1 登录

1. 打开浏览器访问 `http://localhost:5173/`。
2. 输入账号 `engineer01`，密码 `plm123456`。
3. 点击登录。

合格标准：

- 能进入系统首页。
- 浏览器 Network 里登录接口返回 `code=0`。
- 页面右上角能看到当前用户信息。

### 8.2 进入项目详情

1. 点击左侧菜单的项目中心。
2. 在项目列表里选择一个 Product 项目。
3. 进入详情页，确认能看到项目时间轴。
4. 点击当前时间轴节点，例如“样品与工艺”。

合格标准：

- 页面能展示项目基本信息和时间轴。
- 当前节点能显示 BOM、工艺路线、附件区域。
- Network 中能看到项目详情和时间轴接口请求成功。

### 8.3 BOM 创建和明细维护

1. 在 BOM 区域点击新建。
2. 填写 BOM 名称，例如 `超队3.0 样品BOM`。
3. 类型选择或输入 `ebom`。
4. 版本填写 `A`。
5. 保存。
6. 进入 BOM 详情后，新增 2 到 3 条明细。
7. 修改其中一条明细的数量或备注。
8. 删除一条非关键测试明细。

合格标准：

- 保存后 BOM 列表出现新 BOM。
- 明细保存后刷新仍能看到。
- 修改后的数量或备注正确显示。
- 删除后列表不再显示该明细。
- Network 中对应接口为 `/api/v1/projects/{projectId}/boms`、`/api/v1/boms/{bomId}/items`。

### 8.4 BOM 冻结

1. 在 BOM 详情点击冻结。
2. 确认冻结。
3. 冻结后尝试编辑 BOM 或明细。

合格标准：

- BOM 状态显示为 `frozen` 或页面显示冻结状态。
- 编辑、新增、删除等按钮不可用或不再展示。
- 刷新页面后仍然是冻结状态。

### 8.5 工艺路线创建和工序维护

1. 在工艺路线区域点击新建。
2. 填写工艺名称，例如 `超队3.0 样品工艺路线`。
3. 版本填写 `A`。
4. 填写质量要求，例如 `首件确认，外观无划伤，尺寸按图纸检验`。
5. 添加 2 到 3 道工序，例如裁切、注塑、检验。
6. 调整工序顺序。
7. 填写工艺参数 JSON，例如 `{"temperature":"180C","pressure":"standard"}`。
8. 保存。

合格标准：

- 工艺路线保存后列表出现新路线。
- 工序顺序与页面输入一致。
- 质量要求刷新后仍存在。
- JSON 不合法时页面阻止保存并提示。
- Network 中对应接口为 `/api/v1/projects/{projectId}/process-routes` 和 `/api/v1/process-routes/{processId}`。

### 8.6 工艺路线锁定

1. 在工艺路线详情点击锁定。
2. 确认锁定。
3. 锁定后尝试继续编辑路线或工序。

合格标准：

- 工艺路线状态显示为 `locked`。
- 工序编辑、新增、删除不可用。
- 刷新页面后仍然是锁定状态。

### 8.7 当前节点附件上传

1. 保持在项目详情页当前时间轴节点。
2. 在附件区域选择文件分类，例如 `sop`、`sip`、`test_report` 或 `drawing`。
3. 选择本机一个小文件。
4. 填写版本 `A` 和备注。
5. 点击上传。

合格标准：

- 上传成功后附件列表出现该文件。
- 文件名、分类、版本、大小显示正确。
- 后端本机存储目录能看到真实文件。
- 数据库 `plm_attachment` 能看到对应元数据。
- Network 中接口为 `/api/v1/projects/{projectId}/timeline/{nodeKey}/attachments`。

### 8.8 附件下载和删除

1. 在项目详情附件列表点击下载。
2. 确认浏览器下载到了文件。
3. 再选择一条测试附件点击删除。

合格标准：

- 文件存在时下载返回文件流，浏览器能得到文件。
- 删除后页面列表刷新，已删除文件不再展示。
- 如果本机文件被手工移走，下载时后端返回明确错误，而不是空文件。

### 8.9 文件中心查询

1. 点击左侧菜单文件中心。
2. 输入项目 ID 查询。
3. 输入节点 key 查询，例如当前节点的 `nodeKey`。
4. 输入文件分类查询，例如 `sop`。
5. 点击查询。
6. 测试分页、下载、删除。

合格标准：

- 文件中心能查到项目节点上传过的附件。
- 按项目、节点、分类筛选结果正确收敛。
- 空结果时页面显示空状态。
- 查询失败时页面显示错误状态，不伪装成空列表。
- 下载和删除调用真实后端接口。

## 9. 后续维护注意事项

- 上传必须从项目时间轴节点发起，文件中心只负责查询、下载、删除，不做新上传入口。
- BOM 和工艺路线的全局中心目前仍保留快照能力，因为后端没有全局聚合分页接口；后续要做真实中心页时，应先补后端聚合查询。
- 前端只负责只读体验，冻结、锁定、删除、下载权限必须以后端为最终裁决。
- API DTO 不要随意改名，尤其是 `productBomId`、`productBomItemId`、`processId`、`attachmentId`。
- `.env.development` 当前没有固定 API 地址，联调时要确认 `VITE_API_BASE_URL` 指向 `http://localhost:8080`。
- 后续如拆包优化，可考虑对 Element Plus 和业务中心页做动态导入或 manual chunks，目前只是构建警告，不阻塞 M4 验收。
