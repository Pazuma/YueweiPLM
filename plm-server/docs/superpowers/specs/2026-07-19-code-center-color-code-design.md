## 2. 设计目标

在“基础资料”导航下新增通用“编码中心”。首期管理颜色编码，支持查询、新增、编辑、启停和 XLSX 批量导入，并为后续其他编码类型保留扩展能力。

颜色编码接入后，历史 BOM 导入、工作台 BOM 路线颜色和最终投产颜色统一使用编码中心的启用颜色编码，避免自由文本绕过主数据校验。

## 3. 数据模型

新增通用编码表 `plm_code_item`：

| 字段 | 说明 |
| --- | --- |
| `code_item_id` | 主键 |
| `code_type` | 编码类型，首期固定使用 `color` |
| `code_value` | 编码值，按文本保存，例如 `01`、`02` |
| `code_name` | 编码名称，例如 `Morado`、`Negro` |
| `status` | `enabled` 或 `disabled` |
| `sort_order` | 排序值 |
| 标准审计字段 | 创建人、创建时间、修改人、修改时间、删除标记 |

唯一约束为：

```text
code_type + code_value
```

不同编码类型允许使用相同编码值，同一编码类型内不允许重复。编码值必须作为字符串保存，不能丢失前导零。

不增加中文名称、来源文件、导入批次或源更新时间字段。XLSX 导入仅更新编码主数据本身。

## 5. XLSX 导入设计

### 5.1 文件结构

系统读取 `Códigos de color-2026-07-19.xlsx` 的 `Códigos de color` 工作表：

- 第 6 行为业务表头。
- 第 7 行开始为数据。
- `Código color` 映射为 `code_value`。
- `Nombre color` 映射为 `code_name`。
- `Estado` 中 `Enabled` 映射为 `enabled`。
- 数据行顺序映射为 `sort_order`。
- `Actualizado` 不落入编码主表。

当前样本包含 20 条启用颜色编码，例如：

| 编码 | 名称 | 状态 |
| --- | --- | --- |
| `01` | `Morado` | `enabled` |
| `02` | `Negro` | `enabled` |
| `03` | `Humo` | `enabled` |
| `04` | `Blanco` | `enabled` |

### 5.2 导入流程

```text
选择 XLSX
→ 校验工作表与业务表头
→ 从第 7 行解析数据
→ 校验编码、名称和状态
→ 展示新增、更新、无变化和错误预览
→ 用户确认
→ 原子提交
```

同类型同编码已存在时更新名称、状态和排序，不重复创建。提交操作必须幂等。

### 5.3 错误规则

以下情况必须返回明确错误，不得用空结果掩盖：

- 文件不是 XLSX。
- 缺少目标工作表或表头不匹配。
- 编码为空或名称为空。
- 同一文件内颜色编码重复。
- 状态值无法映射。
- 提交令牌不存在、已过期或已提交。

错误预览至少包含 Excel 行号、编码、字段和原因。

## 6. BOM 与投产流程接入

### 6.1 历史 BOM 导入

历史 BOM XLSX 的“适用颜色”改为填写颜色编码。预览时必须满足：

```text
code_type = color
+ code_value 唯一匹配
+ status = enabled
```

颜色编码不存在或已停用时，阻止对应整组 BOM 导入并生成明确错误。

### 6.2 工作台 BOM 路线

新增或编辑 BOM 路线适用颜色时，从编码中心启用颜色中选择，不允许自由创建颜色。路线颜色关系保存 `code_item_id`，同时保留编码值和名称快照用于历史追溯。

### 6.3 投产颜色确认

产品线投产决策和新型号最终发布只展示：

- 编码中心状态为 `enabled` 的颜色；
- 已属于当前 BOM 路线的颜色；
- 路线、正式工序和成本快照完整的颜色。

提交时后端重新校验编码状态和路线归属，不能仅依赖前端候选列表。

### 6.4 历史数据兼容

已有 BOM、路线和 SKU 中的颜色名称继续可读。迁移时按编码值或明确映射关联 `code_item_id`；无法唯一匹配的旧数据不自动猜测，进入待处理清单。

## 7. API 设计

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/code-items` | 分页查询编码，支持类型、关键字和状态筛选 |
| `POST` | `/api/v1/code-items` | 新增编码 |
| `PUT` | `/api/v1/code-items/{id}` | 编辑编码名称和排序 |
| `POST` | `/api/v1/code-items/{id}/enable` | 启用编码 |
| `POST` | `/api/v1/code-items/{id}/disable` | 停用编码 |
| `POST` | `/api/v1/code-items/import/preview` | 上传 XLSX 并预校验 |
| `POST` | `/api/v1/code-items/import/{token}/commit` | 使用一次性令牌确认导入 |

查询成功但无数据时返回成功空分页；校验失败、状态冲突和导入异常返回明确错误。

## 8. 权限与审计

- 查看编码中心沿用基础资料查看权限。

- 操作日志记录编码类型、编码值、操作人、时间和变更前后摘要。
